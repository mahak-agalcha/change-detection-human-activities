# SpaceNet 7 Dataset

This directory contains the raw SpaceNet 7 dataset used for
multi-temporal urban change detection.

## Purpose

The dataset is used to develop and evaluate the data pipeline
and change-detection component of the project.

## Important

Raw dataset files are not committed to GitHub.

Only dataset documentation, metadata, and required small samples
should be stored in the repository.

## Pipeline

Raw satellite imagery
        ↓
Data validation
        ↓
Preprocessing
        ↓
Image alignment
        ↓
Change detection
        ↓
Change mask
